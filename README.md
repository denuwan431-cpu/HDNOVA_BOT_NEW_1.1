# HDNOVA WhatsApp Bot

⚡ Advanced WhatsApp Bot with AI, Auto Status, Anti-Delete & More

## Features
- 🤖 AI Chat (Gemini)
- 📥 Auto Status Download
- 🛡️ Anti-Delete
- 📵 Call Shield
- 🎨 Sticker Maker
- 🔍 Wikipedia Search
- 🌤️ Weather
- 📊 Statistics Dashboard

## Deploy to Railway

1. Fork this repository
2. Connect to Railway
3. Add Environment Variables:
   - `MONGO_URI`
   - `PHONE_NUMBER`
   - `BOT_NAME`
4. Deploy and get pairing code from logs
